# CoachPress Sample Data

This folder contains sample data that you can import into your WordPress site to get a better understanding of how the CoachPress theme works.

## How to Import

1.  Log in to your WordPress admin panel.
2.  Navigate to **Tools > Import**.
3.  If the "WordPress" importer is not installed, click the "Install Now" link.
4.  Once the importer is installed, click the "Run Importer" link.
5.  Click the "Choose File" button and select the `sample-data.xml` file from this folder.
6.  Click the "Upload file and import" button.
7.  On the next screen, you can assign the imported content to an existing user or create a new user. We recommend assigning the content to your own user account.
8.  Check the "Download and import file attachments" box to import the sample images.
9.  Click the "Submit" button.

Once the import is complete, your site will be populated with the sample content, and you can start customizing it to your liking.
